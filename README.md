# Piercer Binary Refinery Pipeline

Encadeie transformações (Base64, Hex, XOR, ROT13, URL, Regex, Strings) em tempo real

## Funcionalidades

- **Seções principais**: Entrada Bruta, Adicionar Etapa ao Pipeline, Saída Final do Pipeline
- **Ações disponíveis**: Copiar Saída Final, + Adicionar Etapa
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8165`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8165`.
