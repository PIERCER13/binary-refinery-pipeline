# Piercer Binary Refinery Pipeline

Encadeie transformações (Base64, Hex, XOR, ROT13, URL, Regex, Strings) in real time

## Features

- **Main Sections**: Entrada Bruta, add Etapa ao Pipeline, Saída Final of Pipeline
- **Available Actions**: copy Saída Final, + add Etapa
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).

## How to Run

1. Run `start.bat` to start the local server on port `8165`, or open `index.html` directly in your browser.
2. Open `http://localhost:8165`.
